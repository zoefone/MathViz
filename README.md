# MathViz

类 GeoGebra 的数学可视化网站，支持 MVZ 代码格式、AI 生成、初中/高中模板。

## 启动

```bash
cd C:\Users\Lenovo\cursor-project\mathviz
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 在线访问（手机/平板）

部署后地址：**https://zoefone.github.io/MathViz/**

## 功能

- JSXGraph 动态几何画布（可拖拽点、缩放平移）
- MVZ JSON 代码格式编辑与运行
- 18 个初中/高中预设模板（含辅助线）
- AI 双模式：API（GPT/Claude/Gemini/中转站）+ 浏览器本地 WebLLM
- 导出 PNG/SVG、保存/加载 .mvz、分享链接
- 黑白灰 Apple 风 UI，移动端适配，中英文切换
